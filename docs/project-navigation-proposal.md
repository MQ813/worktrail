# 프로젝트 탐색·AI 작업 공간 미리보기

검토일: 2026-11-15. 사용자가 제안한 5개 탭으로 프로토타입을 갱신했다.
기존 앱 상태는 `b4e3ad5`에 커밋되어 있고, 이후 작업은
`prototypes/project-create/`의 HTML/CSS/JavaScript 미리보기다.
본앱의 라우트·AI 실행·DB·실행 파일은 변경하지 않는다.

## 현재 구성

```text
프로젝트
├─ 프로젝트 목록        검색·상태 필터·프로젝트 개요
├─ 연결 검토            문의 근거·연결 대상 선택
├─ 프로젝트 추가        직접 입력·작성 내용 요약
├─ AI                   자유 요청·대상 선택·결과 예시
└─ 작업 이력            최근 요청·대상·처리 상태
```

어느 탭에 있어도 같은 탐색을 유지한다. 프로젝트 추가는 직접 입력에 집중하고,
JOB 폴더 가져오기는 제거했다. 생성에만 붙어 있던 AI를 별도 작업 공간으로 옮겨
신규 생성과 기존 프로젝트 업데이트를 같은 입력에서 요청할 수 있게 했다.
이전 검토안의 3개 탭과 생성 방식별 하위 탐색은 이 구성으로 대체한다.

## AI 요청과 결과

| 요청 | 결과 예시 |
|---|---|
| Nova DAC 개발 프로젝트 만들어줘 | 이름·목적·일정을 편집할 수 있는 신규 생성안 |
| Atlas 일정과 cell 이슈 업데이트해줘 | 기존 프로젝트의 공통 일정과 하위 이슈 기록을 분리한 변경 전후 |
| 3.3V GPIO 프로젝트 찾아줘 | 목적·일정·하위 이슈·일치 단서, 해당 프로젝트로 요청 이어가기 |
| 기존 프로젝트면 수정하고 없으면 만들어줘 | 기존 대상 일치 시 수정안, 일치 항목이 없으면 신규 생성안 |

요청은 자유롭게 입력한다. 예시 버튼은 시작 문장을 채워 주는 보조 도구이며,
처리 방식 선택을 필수로 요구하지 않는다. 대상을 알면 직접 선택하고, 모르면
‘요청 내용에서 찾기’를 사용한다. 참고 문의는 선택적으로 펼친다.

결과는 넓은 화면에서 요청 옆에, 작은 화면에서 요청 아래에 표시한다.
변경할 대상과 내용을 확인하고 직접 편집한 뒤 ‘예시 반영’을 누르면
이 미리보기의 목록과 이력에만 반영된다. 실제 검색·AI·저장은 실행하지 않으며
준비된 키워드에 따른 합성 결과를 사용한다. 새로고침하면 초기화된다.
대상이 모호하거나 생성 요청과 선택한 기존 대상이 충돌하면 추가 정보를 안내한다.

## 탭·drawer·새 창 판단

5개 탭은 목록 조회, 연결 검토, 직접 추가, AI 요청, 이력 확인이라는 서로 다른
작업을 지속해서 오가는 데 적합하다. AI가 여러 프로젝트를 찾거나 신규/기존 대상을
판단하려면 특정 프로젝트 상세에만 위치시키는 것보다 독립된 목적지가 유리하다.
특정 프로젝트의 짧은 편집은 계속 해당 상세의 내용 가까이에 둘 수 있다.

많은 입력과 변경 전후를 담는 AI 작업을 drawer에 넣으면 본문이 좁고 내부 스크롤이
늘어난다. 새 창도 닫기·포커스·입력 보존 부담을 늘리므로 기본 흐름으로 쓰지 않는다.
탭마다 URL을 제공하고, 뒤로 가기와 입력·필터 보존을 지원한다.

사용했다. 결과 수정을 통해 요청을 이어가도록 했으며 별도 평가 버튼은 추가하지 않았다.
마케팅 히어로·사진·무작위 팔레트·장면 효과·다른 프레임워크는 도입하지 않았다.
