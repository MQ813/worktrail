# AI 프로젝트 생성·업데이트 계획

상태: 구현·검증 완료 (2026-11-15)

## 합의한 동작
- 자연어와 선택한 기존 문의로 신규 프로젝트를 생성하거나 기존 프로젝트를 수정한다.
- 미연결 변경마다 기존 프로젝트 연결·신규 프로젝트·관리 대상 아님 행동을 제공한다.
- AI는 실제 내용을 반영하고 사용자 확인 여부를 별도로 보존한다. 확인은 업무 완료가 아니다.
- 공정 + 개발 대상 + 목표/산출물로 작은 프로젝트를 구분한다. 큰 범위/긴 이력은 상세 하위 이슈로 관리한다.
- 제공된 정보만 사용한다. 누락은 TBD, 모호함/상충은 확인 필요로 문서화한다.
- 새 파일 첨부는 제외한다. 자동 전체 미연결 탐색은 후속 범위다.

## 구현 순서
1. DB v7: AI 요청, 변경 전후 이력, 확인 상태, 프로젝트 목표일/spec/공정/대상.
2. 기존 단일 worker/실제 OpenCode 연결에 프로젝트 명령 단계를 추가한다.
3. 요청 시 입력·문의 revision·프로젝트 버전을 보존하고, 결과 적용 시 재검증한다.
4. 중복 요청, 잘못된 대상, 상충 수정, 오래된 결과를 차단한다. 생성·연결·변경은 원자적으로 적용한다.
5. 자연어 폼, 미연결 항목 행동, 요청 상태, 미확인 이력, 확인·되돌리기를 추가한다.
6. 자동 문의 업데이트도 같은 자동 반영·확인 이력 경로를 사용한다. 과거 재구성/삭제/상충은 기존 검토 경로를 유지한다.
7. 기능 회귀 및 폐기 가능한 샘플 서버의 실제 Edge에서 좁은/넓은 화면, 키보드, 상태, 긴 한국어, 저장 흐름을 확인한다.

## 설계 기준
- 대상이 불명확하면 질문/대상 선택이 필요한 상태로 보존하며 임의 생성·수정하지 않는다.
- 명시 신규 요청은 신규 생성하되 같은 이름과 반복 실행은 중복 생성하지 않는다.
- 변경 전후 전체 문서 상태와 입력 근거를 보존한다. 후속 수동/AI 수정이 있으면 되돌리기를 차단한다.
- 기존 할일 ID를 연결하며 업무 완료나 수행 기록을 자동 생성하지 않는다.
- Taste: 업무 콘텐츠·정렬·간결한 행동 문구. UI UX Pro Max: 입력 라벨·로딩/성공/실패·키보드.
- 마케팅 히어로, 외부 폰트, 애니메이션 gate는 업무 앱 맥락에 맞지 않아 적용하지 않는다.

## 구현 결과와 검증

- DB v7 snapshot 이관, 명령 큐/실제 OpenCode 연결, 자동 반영·사후 확인·변경 전후 이력·되돌리기를 구현했다.
- 미연결 변경의 신규 생성·기존 대상 선택·관리 대상 제외와 자연어 생성/수정, 목표일/spec/공정/개발 대상 편집을 구현했다.
- 기존 프로젝트의 첫 AI 명령 적용 이후 신규 문의 변경을 자동 반영한다. 기존 미확정 제안/과거 재구성/삭제/상충은 이전 검토 흐름을 보존한다.
- 생성 취소는 이력과 연결을 보존하는 cancelled 상태다. 되돌리기는 후속 편집이 없을 때 내용만 복구하며 하위 이슈 자체는 추적용으로 남긴다.
- 자동 테스트 98개 통과, Ruff 통과. 신규 테스트 12개는 중복 키·생성/연결·일정 교체·확인/취소·재시도·대상/근거/버전/연결 해제 충돌·자동 문의 업데이트·미확인 내보내기를 검증한다.
- 실제 Edge 신규 화면 8개 + 공통 36개 화면/너비 조합과 사용자 흐름 통과. 근거: `runtime/ai-project-review-1794707505972398700/`.
- 실제 OpenCode/OpenAI로 합성 문의 기반 신규 생성과 목표일 2027-03-31 → 2027-04-15 업데이트를 같은 API/worker로 실행했다. 요청 입력·실제 출력·시도 로그는 샘플 DB에 보존된다.
- Windows 0.5.0 빌드 및 실제 WebView2 실행/단일 인스턴스/worker 복구/재기동 데이터 보존 통과. `runtime/ai-project-native-final/verification.json`.
- 배포 EXE에서도 신규 명령 API → 내장 worker → 생성 → 사용자 확인을 검증했다. `runtime/ai-project-native-command-final/command-verification.json`.
- 샘플 프로젝트 5개 + 대상 선택 필요 요청을 `runtime/project-samples-20261115-final`에 별도 보존했다. 독립/문의 연결/하위 이슈/확인 완료/일정 변경을 포함한다. 실제 AI 호출 외 나머지 사례는 재현 가능한 합성 응답이다.
- 사용자 승인 완료 샘플은 테스트 시나리오에서 확인 상태를 설정한 것으로 실제 업무 승인이나 수행 실적을 뜻하지 않는다.

## 범위와 한계

새 파일 첨부와 전체 미연결 항목 자동 발굴은 후속 범위다. 모델의 의미상 매칭·요구사항 해석 정확도는 사후 확인이 필요하다. 입력 본문 인용 일치는 검증하지만 기술적 진실성이나 의미상 중복을 완전히 증명하지 않는다. 실제 사내 데이터/DRM·장기 운영은 검증하지 않았다. 사용법과 운영 차이는 `docs/ai-projects.md`에 기록했다.
